# 发布工作台

- 从首页粘贴 YouTube 视频链接，或在「频道监控」批量选择视频。打开任一发布任务可查看成片、上传和审核的实际进度。
- 「成片已导出」表示本机 MP4 已完成。「审核中」表示 B 站已收到稿件或正在做发布核验。「已发布」表示稿件通过审核且可匿名访问。
- 「文案待处理」可编辑标题、简介、分区和标签。保存后从原任务继续；不会重新生成配音。
- 「投稿待核对」只查询原稿件，避免重复投稿。上传回执、稿件编号和审查记录跨重启保留。
- 「发布设置」可指定投稿使用的大模型。不可用时，使用本机 LibreTranslate 和频道模板的有效备用分区、标签；备用配置不全时保留可编辑的文案草稿。
- 关窗口后队列留在托盘。暂停队列后，已在发送的操作可以完成并保存回执，新的操作等恢复后再开始。

升级使用原有配置和数据库，已取消的任务不会恢复。回退程序前先退出桌面程序；已提交的稿件记录必须保留，不能把发布数据库覆盖为更早的备份，否则会丢失稿件身份信息。
